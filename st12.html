문항 1기초 1 · 문자열 생성과 인덱싱

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

s1 = 'Hello'
s2 = "Python"
s3 = """이것은
여러 줄에 걸친
문자열입니다."""

print(s1)
print("s2의 첫 번째 글자:", s2[0])    # 'P'
print("s2의 마지막 글자:", s2[-1])   # 'n'
상세 풀이 보기
정답 출력
Hello
s2의 첫 번째 글자: P
s2의 마지막 글자: n
상세 풀이

s1은 Hello이므로 그대로 출력된다. s2[0]은 첫 글자 P이고, s2[-1]은 마지막 글자 n이다. s3는 변수에 저장만 되고 print하지 않으므로 출력되지 않는다.

문항 2기초 2 · 문자열 연결과 반복

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

first = "파이썬은 "
second = "재미있다!"

# 문자열 연결
sentence = first + second
print(sentence)

# 문자열 반복
laugh = "하" * 5
print(laugh)
상세 풀이 보기
정답 출력
파이썬은 재미있다!
하하하하하
상세 풀이

+ 연산자는 문자열을 이어 붙인다. first 뒤에 공백이 포함되어 있어 자연스럽게 문장이 된다. 문자열에 * 5를 하면 같은 문자열이 5번 반복된다.

text = "안녕하세요, 인수샘입니다."

문항 4기초 4 · 문자열 슬라이싱

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

상세 풀이 보기
정답 출력
생년월일: 990101
성별 코드: 1
상세 풀이

jumin[:6]은 인덱스 0부터 5까지의 문자열인 990101을 가져온다. jumin[7]은 하이픈 다음 첫 번째 숫자인 1이다.

문항 6응용 1 · 문자열 나누기

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

data = "홍길동,구운몽,인수샘"
names = data.split(",") # 쉼표를 기준으로 나눔
print(names)

address = "서울시 강남구 역삼동"
parts = address.split() # 공백을 기준으로 나눔
print(parts)
상세 풀이 보기
정답 출력
['홍길동', '구운몽', '인수샘']
['서울시', '강남구', '역삼동']
상세 풀이

split(',')은 쉼표를 기준으로 문자열을 나누어 리스트를 만든다. split()에 인자를 주지 않으면 공백을 기준으로 나눈다.

문항 11심화 1 · 리스트를 문자열로 합치기

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

words = ["Life", "is", "too", "short"]

# " " (공백)을 구분자로 하여 합치기
sentence = " ".join(words)
print(sentence)

# "-"을 구분자로 하여 합치기
date_parts = ["2026", "03", "21"]
date_string = "-".join(date_parts)
print(date_string)
상세 풀이 보기
정답 출력
Life is too short
2026-03-21
상세 풀이

join()은 리스트의 문자열 요소들을 지정한 구분자로 연결한다. 첫 번째는 공백, 두 번째는 하이픈을 구분자로 사용한다.

문항 12심화 2 · 위치 찾기

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

text = "apple, banana"

# .find(): 찾는 문자열이 없으면 -1을 반환합니다.
print("banana의 위치:", text.find("banana"))
print("orange의 위치:", text.find("orange")) # -1

# .index(): 찾는 문자열이 없으면 ValueError 오류를 발생시킵니다.
print("apple의 위치:", text.index("apple"))
# print(text.index("orange")) # 이 코드는 오류를 발생시킴
상세 풀이 보기
정답 출력
banana의 위치: 7
orange의 위치: -1
apple의 위치: 0
상세 풀이

apple, banana에서 banana는 인덱스 7에서 시작한다. orange는 없으므로 find()가 -1을 반환한다. apple은 맨 앞에서 시작하므로 index 값은 0이다.

문항 14심화 4 · 문자열 구성 확인

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

s1 = "12345"
s2 = "Python"

print(f"'{s1}'는 숫자입니까? {s1.isdigit()}")
print(f"'{s2}'는 문자로만 되어 있습니까? {s2.isalpha()}")
상세 풀이 보기
정답 출력
'12345'는 숫자입니까? True
'Python'는 문자로만 되어 있습니까? True
상세 풀이

isdigit()은 문자열이 숫자로만 이루어졌는지 확인한다. isalpha()는 알파벳 문자로만 이루어졌는지 확인한다. 두 조건 모두 참이다.
