문항 1Numpy 배열 생성

다음 코드를 실행했을 때의 출력 결과를 쓰시오.

import numpy as np

arr1d = np.array([1, 2, 3, 4, 5])
print("--- 1차원 배열 ---")
print(arr1d)

arr2d = np.array([[1, 2, 3], [4, 5, 6]])
print("\n--- 2차원 배열 ---")
print(arr2d)
상세 풀이 보기
정답 출력
--- 1차원 배열 ---
[1 2 3 4 5]

--- 2차원 배열 ---

1차원 배열은 대괄호 한 겹으로 출력되고, 2차원 배열은 행 단위로 줄이 나뉘어 출력된다. print("\n...") 때문에 중간에 빈 줄이 생긴다.

문항 2배열의 속성 확인

상세 풀이 보기
정답 출력

배열은 2행 3열이므로 shape는 (2, 3)이다. 중첩 리스트로 만든 2차원 배열이라 ndim은 2이다. 정수 배열의 dtype은 일반적인 64비트 환경에서 int64로 표시된다.

상세 풀이 보기

문항 5통계 함수 활용

다음 코드를 실행했을 때의 출력 결과를 쓰시오.

import numpy as np
arr = np.array([[1, 2], [3, 4]])

print("전체 합계:", np.sum(arr))
print("열 기준 평균 (axis=0):", np.mean(arr, axis=0))
print("행 기준 최댓값 (axis=1):", np.max(arr, axis=1))
상세 풀이 보기
정답 출력
전체 합계: 10
열 기준 평균 (axis=0): [2. 3.]
행 기준 최댓값 (axis=1): [2 4]

전체 합은 1+2+3+4=10이다. axis=0은 열 방향 평균이므로 [1,3]의 평균 2, [2,4]의 평균 3이다. axis=1은 각 행에서 최댓값을 구한다.

문항 12행렬 곱셈

다음 코드를 실행했을 때의 출력 결과를 쓰시오.

import numpy as np
mat1 = np.array([[1, 2], [3, 4]])
mat2 = np.array([[5, 6], [7, 8]])

result = mat1 @ mat2
print("행렬 곱셈 결과 (@):\n", result)

result_dot = np.dot(mat1, mat2)
print("\n행렬 곱셈 결과 (dot):\n", result_dot)
상세 풀이 보기
정답 출력
행렬 곱셈 결과 (@):
 [[19 22]
 [43 50]]

행렬 곱셈 결과 (dot):
 [[19 22]
 [43 50]]

행렬 곱셈은 행과 열을 곱해 더한다. 첫 원소는 1×5+2×7=19이다. @와 np.dot은 이 경우 같은 결과를 낸다.

문항 13np.where 조건부 값 할당

다음 코드를 실행했을 때의 출력 결과를 쓰시오.

import numpy as np
arr = np.array([-2, -1, 0, 1, 2])

result = np.where(arr > 0, '양수', '음수')

print("원본 배열:", arr)
print("변환 결과:", result)

cleaned = np.where(arr < 0, 0, arr)
print("정제된 데이터 (음수 제거):", cleaned)
상세 풀이 보기
정답 출력
원본 배열: [-2 -1  0  1  2]
변환 결과: ['음수' '음수' '음수' '양수' '양수']
정제된 데이터 (음수 제거): [0 0 0 1 2]

arr > 0 조건이 참이면 '양수', 거짓이면 '음수'가 선택된다. 0은 0보다 크지 않으므로 음수 쪽으로 분류된다. arr < 0인 값은 0으로 바뀐다.
