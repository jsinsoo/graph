문항 4기초 4 · 여러 개의 매개변수와 반환 값

def calculate_rectangle(width, height):
    """사각형의 넓이와 둘레를 계산하여 반환하는 함수"""
    area = width * height
    perimeter = 2 * (width + height)
    return area, perimeter

# 함수 호출 및 결과 저장 (튜플 형태로 반환됨)
rect_area, rect_perimeter = calculate_rectangle(10, 20)
print(f"넓이: {rect_area}, 둘레: {rect_perimeter}")
상세 풀이 보기
정답 출력
넓이: 200, 둘레: 60
상세 풀이

가로 10, 세로 20이므로 넓이는 10 × 20 = 200입니다. 둘레는 2 × (10 + 20) = 60입니다. 두 값이 각각 rect_area와 rect_perimeter에 저장됩니다.

문항 5기초 5 · 기본값 매개변수

def power(number, exponent=2):

print(f"3의 제곱: {power(3)}")      # exponent=2 사용
print(f"2의 10승: {power(2, 10)}") # exponent=10 사용

power(3)은 exponent를 생략했으므로 기본값 2가 적용되어 3² = 9입니다. power(2, 10)은 exponent가 10으로 지정되어 2¹⁰ = 1024입니다.

문항 6응용 1 · 가변 인자 *args 활용

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

def sum_all(*args):
    """입력받은 모든 숫자의 합을 구하는 함수"""
    total = 0
    for num in args:
        total += num
    return total

print(f"합계: {sum_all(1, 2, 3, 4, 5)}")

상세 풀이

*args는 여러 개의 인자를 튜플처럼 받습니다. 1, 2, 3, 4, 5를 차례로 더하면 15가 되어 출력됩니다.

문항 9응용 4 · 재귀 함수

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

def factorial(n):
    """팩토리얼을 구하는 재귀 함수"""
    if n == 1:
        return 1
    return n * factorial(n - 1)

print(f"5! = {factorial(5)}")
상세 풀이 보기
정답 출력

상세 풀이

factorial(5)는 5 × 4 × 3 × 2 × 1을 계산합니다. n이 1이 되면 1을 반환하며 재귀 호출이 종료되어 최종값 120이 출력됩니다.

문항 11심화 2 · 클로저

def outer_func(base_num):
    """바깥 함수: 기준 숫자를 기억"""

    return inner_func

# base_num(5)를 기억하는 함수가 반환됨
multiplier_by_5 = outer_func(5)
print(f"5 * 3 = {multiplier_by_5(3)}")

정답 출력
5 * 3 = 15
상세 풀이

outer_func(5)는 base_num 값 5를 기억하는 inner_func를 반환합니다. multiplier_by_5(3)을 호출하면 5 × 3 = 15가 반환되어 출력됩니다.

문항 12심화 3 · 데코레이터

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

import time

def timer_decorator(original_func):
    """함수의 실행 시간을 측정하는 데코레이터"""
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = original_func(*args, **kwargs)
        end_time = time.time()
        print(f"'{original_func.__name__}' 실행 시간: {end_time - start_time:.5f}초")
        return result
    return wrapper

@timer_decorator
def long_task(n):
    """합계를 구하는 작업 시뮬레이션"""
    return sum(range(n))

long_task(1000000)
상세 풀이 보기
정답 출력
'long_task' 실행 시간: 실행할 때마다 달라지는 값초
상세 풀이

long_task(1000000)의 반환값은 print하지 않으므로 합계는 화면에 나오지 않습니다. 데코레이터 wrapper 안의 print문만 실행되며, 실행 시간은 컴퓨터 상태마다 달라지므로 숫자는 매번 다를 수 있습니다.

문항 13심화 4 · 제너레이터

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

def number_generator(n):
    """0부터 n-1까지 숫자를 생성하는 제너레이터"""
    for i in range(n):
        yield i

for num in number_generator(5):
    print(f"생성된 숫자: {num}")
상세 풀이 보기
정답 출력
생성된 숫자: 0

생성된 숫자: 2
생성된 숫자: 3
생성된 숫자: 4
상세 풀이

number_generator(5)는 0부터 4까지 값을 하나씩 yield합니다. for문이 각 값을 받아 생성된 숫자: 형식으로 다섯 줄을 출력합니다.
