문항 7응용 2 · 결측치 처리하기

import pandas as pd
import numpy as np

    '이름': ['인수샘', '홍길동', '구운몽'],

문항 12심화 2 · apply 함수 적용

다음 Pandas 코드를 실행했을 때의 출력 결과를 줄바꿈과 공백까지 고려하여 서술하시오.

import pandas as pd

df = pd.DataFrame({'점수1': [80, 90, 70], '점수2': [85, 95, 75]})

df['최고점수'] = df.apply(lambda row: max(row['점수1'], row['점수2']), axis=1)
df['평균점수'] = df.apply(lambda row: (row['점수1'] + row['점수2']) / 2, axis=1)
print(df)
상세 풀이 보기
정답 출력
   점수1  점수2  최고점수  평균점수
0   80   85    85  82.5
1   90   95    95  92.5
2   70   75    75  72.5
상세 풀이

axis=1은 행 단위로 함수를 적용한다. 각 행에서 두 점수 중 큰 값을 최고점수로, 두 점수의 평균을 평균점수로 계산한다.
