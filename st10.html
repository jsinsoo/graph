문항 1기초 1 · 딕셔너리 생성 및 값 접근

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

student = {
    "name": "홍길동",
    "id": 202301,
    "major": "컴퓨터공학"
}

# 'name' 키를 이용해 값에 접근
print(f"학생 이름: {student['name']}")

# get() 메서드 활용 (키가 없어도 오류 없이 기본값 반환 가능)
print(f"학생 학년: {student.get('grade', '정보 없음')}")
상세 풀이 보기
정답 출력
학생 이름: 홍길동
학생 학년: 정보 없음
상세 풀이

student['name']은 name 키의 값인 홍길동을 출력한다. grade 키는 없으므로 get('grade','정보 없음')은 오류 대신 기본값 정보 없음을 반환한다.

문항 2기초 2 · 새 키-값 쌍 추가 및 수정

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

person = {}

# 데이터 추가
person['name'] = '인수샘'
person['age'] = 30
print(f"추가 후: {person}")

# 기존 값 수정
person['age'] = 31
print(f"수정 후: {person}")
상세 풀이 보기
정답 출력
추가 후: {'name': '인수샘', 'age': 30}
수정 후: {'name': '인수샘', 'age': 31}
상세 풀이

처음에는 빈 딕셔너리이다. name과 age를 추가하면 두 쌍이 저장된다. 이후 age 키에 31을 다시 대입하므로 기존 30이 31로 바뀐다.

문항 3기초 3 · 딕셔너리 요소 삭제

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

car = {"brand": "현대", "model": "아이오닉", "year": 2024}

# 'year' 키와 해당 값 삭제
del car['year']
print(f"del 후: {car}")

# pop()을 사용하여 값을 꺼내오면서 삭제
model_name = car.pop('model')
print(f"삭제된 모델: {model_name}, 현재 딕셔너리: {car}")
상세 풀이 보기
정답 출력
del 후: {'brand': '현대', 'model': '아이오닉'}
삭제된 모델: 아이오닉, 현재 딕셔너리: {'brand': '현대'}
상세 풀이

del car['year']로 year 항목이 삭제된다. pop('model')은 model 값을 꺼내 model_name에 저장하고 동시에 딕셔너리에서 model 항목을 제거한다.

문항 4기초 4 · 모든 키와 값 순회

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

inventory = {"apple": 10, "banana": 5, "cherry": 20}

print(f"모든 품목: {list(inventory.keys())}")
print(f"모든 수량: {list(inventory.values())}")

# 키와 값을 동시에 순회
for item, count in inventory.items():
    print(f"{item}의 재고는 {count}개입니다.")
상세 풀이 보기
정답 출력
모든 품목: ['apple', 'banana', 'cherry']
모든 수량: [10, 5, 20]
apple의 재고는 10개입니다.
banana의 재고는 5개입니다.
cherry의 재고는 20개입니다.
상세 풀이

keys()는 키 목록, values()는 값 목록을 반환한다. Python 3.7 이상에서는 입력 순서가 유지되므로 apple, banana, cherry 순서로 items() 반복문이 실행된다.

문항 5기초 5 · 딕셔너리 비우기 및 확인

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

user = {"id": "user01", "status": "active"}

print("status 키가 있나요?", 'status' in user)

user.clear()
print(f"비운 후 결과: {user}")
상세 풀이 보기
정답 출력
status 키가 있나요? True
비운 후 결과: {}
상세 풀이

'status' in user는 status 키가 존재하므로 True이다. clear()는 딕셔너리 안의 모든 키-값 쌍을 삭제해 빈 딕셔너리 {}가 된다.

문항 6응용 1 · 딕셔너리 컴프리헨션

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

users = ["인수샘", "홍길동", "구운몽"]
# 이름의 길이를 값으로 갖는 딕셔너리 생성
name_lengths = {name: len(name) for name in users}

print(f"이름 길이 정보: {name_lengths}")
상세 풀이 보기
정답 출력
이름 길이 정보: {'인수샘': 3, '홍길동': 3, '구운몽': 3}
상세 풀이

딕셔너리 컴프리헨션은 users의 각 이름을 키로, len(name)을 값으로 저장한다. 세 이름은 모두 세 글자이므로 값은 모두 3이다.

문항 7응용 2 · 딕셔너리 정렬

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

scores = {"수학": 100, "영어": 80, "국어": 95, "과학": 85}

# 값을 기준으로 내림차순 정렬 (람다 함수 활용)
sorted_scores = sorted(scores.items(), key=lambda item: item[1], reverse=True)

print(f"점수 내림차순 정렬: {sorted_scores}")
상세 풀이 보기
정답 출력
점수 내림차순 정렬: [('수학', 100), ('국어', 95), ('과학', 85), ('영어', 80)]
상세 풀이

scores.items()는 (과목, 점수) 쌍을 만든다. key=lambda item: item[1]은 점수를 기준으로 정렬하게 하며 reverse=True라서 큰 점수부터 배치된다.

문항 8응용 3 · 복잡한 데이터 구조화

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

api_response = {

first_product_second_tag = api_response["data"][0]["tags"][1]

상세 풀이 보기

첫 번째 상품의 두 번째 태그: 컴퓨터

api_response['data']는 상품 딕셔너리들의 리스트이다. [0]은 첫 번째 상품, ['tags']는 태그 리스트, [1]은 두 번째 태그인 컴퓨터를 뜻한다.

문항 9응용 4 · setdefault() 메서드 활용

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

students = [('John', 'A'), ('Jane', 'B'), ('Dave', 'A'), ('Sarah', 'C')]
grades = {}

for name, grade in students:
    # 해당 성적(grade) 리스트가 없으면 빈 리스트를 만들고 이름을 추가
    grades.setdefault(grade, []).append(name)

print(f"성적별 학생 분류: {grades}")
상세 풀이 보기
정답 출력
성적별 학생 분류: {'A': ['John', 'Dave'], 'B': ['Jane'], 'C': ['Sarah']}
상세 풀이

setdefault(grade, [])는 grade 키가 없으면 빈 리스트를 만든다. 그 리스트에 학생 이름을 append하므로 같은 성적끼리 학생 이름이 묶인다.

문항 10심화 1 · 두 딕셔너리 병합

다음 파이썬 코드를 실행했을 때의 출력 결과를 줄바꿈까지 고려하여 서술하시오.

base_info = {"name": "구운몽", "age": 25}
extra_info = {"major": "국문학", "city": "서울"}

# 병합 연산자 | 사용
full_profile = base_info | extra_info
print(f"병합된 프로필: {full_profile}")

# 업데이트 연산자 |= 사용 (원본 수정)
base_info |= {"status": "졸업"}
print(f"업데이트된 원본: {base_info}")
상세 풀이 보기
정답 출력
병합된 프로필: {'name': '구운몽', 'age': 25, 'major': '국문학', 'city': '서울'}
업데이트된 원본: {'name': '구운몽', 'age': 25, 'status': '졸업'}
상세 풀이

| 연산자는 두 딕셔너리를 합쳐 새 딕셔너리 full_profile을 만든다. |= 연산자는 base_info 자체에 status 항목을 추가하여 원본을 직접 수정한다.
