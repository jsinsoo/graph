문항 1기본적인 선 그래프(Line Plot)

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [2, 4, 6, 8]

plt.plot(x, y)
plt.show()
상세 풀이 보기
모범 답안
점 (1,2), (2,4), (3,6), (4,8)을 연결한 기본 선 그래프가 나타난다.
상세 풀이

x와 y 리스트의 같은 위치 값이 좌표가 된다. plt.plot(x, y)는 네 좌표를 선으로 연결하고, plt.show()는 그래프 창을 화면에 보여준다.

문항 2제목과 축 레이블 추가하기

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt

plt.rcParams['font.family'] = 'Malgun Gothic'

x = [1, 2, 3, 4]
y = [10, 20, 25, 30]

plt.plot(x, y)
plt.title("월별 성적 변화")
plt.xlabel("월 (Month)")
plt.ylabel("점수 (Score)")
plt.show()
상세 풀이 보기
모범 답안
제목이 '월별 성적 변화'이고 x축 이름은 '월 (Month)', y축 이름은 '점수 (Score)'인 선 그래프가 나타난다.
상세 풀이

plot은 월별 점수 변화를 선으로 나타낸다. title, xlabel, ylabel은 각각 그래프 제목, x축 이름, y축 이름을 설정한다.

문항 3선의 스타일과 색상 변경하기

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [1, 4, 9], 'ro--')
plt.show()

plt.plot([1, 2, 3], [1, 2, 3], color='blue', marker='s', linestyle=':', linewidth=2)
plt.show()
상세 풀이 보기
모범 답안
첫 번째 그래프는 빨간 원 마커와 점선으로 y값 1, 4, 9를 연결한다. 두 번째 그래프는 파란 사각형 마커와 점선으로 y값 1, 2, 3을 연결한다.
상세 풀이

'ro--'는 red, circle marker, dashed line을 뜻한다. 두 번째 plot은 color, marker, linestyle, linewidth를 직접 지정한다.

문항 4여러 개의 그래프와 범례

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt

days = [1, 2, 3, 4, 5]
temp_hong = [22, 24, 21, 25, 23]
temp_insu = [20, 22, 25, 22, 21]

plt.plot(days, temp_hong, label='홍길동')
plt.plot(days, temp_insu, label='인수샘')

plt.legend()
plt.title("일별 체온 변화 비교")
plt.show()
상세 풀이 보기
모범 답안
제목이 '일별 체온 변화 비교'인 그래프에 홍길동과 인수샘 두 개의 선 그래프가 함께 나타나고 범례가 표시된다.
상세 풀이

plot을 두 번 호출했기 때문에 한 좌표 영역에 두 선이 그려진다. label 값은 legend()에 의해 범례로 표시된다.

문항 5축 범위 지정하기

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [10, 20, 30, 40]

plt.plot(x, y)
plt.xlim(0, 5)
plt.ylim(0, 50)
plt.show()
상세 풀이 보기
모범 답안
x축 범위가 0부터 5까지, y축 범위가 0부터 50까지로 고정된 선 그래프가 나타난다.
상세 풀이

xlim은 x축 표시 범위, ylim은 y축 표시 범위를 지정한다. 데이터는 (1,10)부터 (4,40)까지 이어진다.

문항 6막대 그래프(Bar Chart)

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt

categories = ['국어', '영어', '수학', '과학']
scores = [85, 90, 78, 92]

plt.bar(categories, scores, color='skyblue')
plt.title("홍길동의 과목별 성적")
plt.show()
상세 풀이 보기
모범 답안
국어 85, 영어 90, 수학 78, 과학 92를 나타내는 하늘색 막대 그래프가 나타난다.
상세 풀이

bar는 범주형 x축과 수치형 y축을 막대로 표현한다. 가장 높은 막대는 과학 92이고 가장 낮은 막대는 수학 78이다.

문항 7산점도(Scatter Plot)

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt
import numpy as np

np.random.seed(0)
x = np.random.rand(50)
y = np.random.rand(50)
colors = np.random.rand(50)
area = (30 * np.random.rand(50))**2

plt.scatter(x, y, s=area, c=colors, alpha=0.5)
plt.title("무작위 분포 산점도")
plt.show()
상세 풀이 보기
모범 답안
제목이 '무작위 분포 산점도'인 그래프에 50개의 점이 다양한 크기와 색상, 0.5 투명도로 흩어져 나타난다.
상세 풀이

scatter는 x, y 좌표에 점을 찍는다. s는 점 크기, c는 색상 값, alpha는 투명도를 조절한다. seed를 사용해 난수 결과를 고정했다.

문항 8히스토그램(Histogram)

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt
import numpy as np

np.random.seed(0)
data = np.random.randn(1000)

plt.hist(data, bins=30, color='green', edgecolor='black')
plt.title("데이터 분포 히스토그램")
plt.show()
상세 풀이 보기
모범 답안
제목이 '데이터 분포 히스토그램'인 초록색 히스토그램이 나타나며, 검은 테두리를 가진 30개의 구간으로 데이터 분포가 표시된다.
상세 풀이

randn은 평균 0 근처에 많이 모이는 정규분포 난수를 만든다. hist는 값의 범위를 bins 수만큼 나누어 빈도를 막대로 표현한다.

문항 9파이 차트(Pie Chart)

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt

labels = ['사과', '바나나', '딸기', '포도']
sizes = [25, 35, 20, 20]
explode = (0, 0.1, 0, 0)

plt.pie(sizes, explode=explode, labels=labels, autopct='%1.1f%%', shadow=True)
plt.title("좋아하는 과일 비율")
plt.show()
상세 풀이 보기
모범 답안
사과 25.0%, 바나나 35.0%, 딸기 20.0%, 포도 20.0%의 파이 차트가 나타나며 바나나 조각만 약간 떨어져 보인다.
상세 풀이

pie는 전체 비율을 원형 조각으로 나타낸다. explode의 두 번째 값이 0.1이므로 바나나 조각만 강조되어 분리된다.

문항 10여러 개의 플롯 나누어 그리기

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y1 = [1, 4, 9, 16]
y2 = [1, 2, 3, 4]

fig, ax = plt.subplots(1, 2)

ax[0].plot(x, y1, 'r')
ax[0].set_title("제곱")

ax[1].plot(x, y2, 'g')
ax[1].set_title("직선")

plt.tight_layout()
plt.show()
상세 풀이 보기
모범 답안
1행 2열로 나뉜 화면에 왼쪽에는 제목이 '제곱'인 빨간 선 그래프, 오른쪽에는 제목이 '직선'인 초록 선 그래프가 나타난다.
상세 풀이

subplots(1, 2)는 두 개의 좌표 영역을 만든다. ax[0]에는 제곱 형태 데이터, ax[1]에는 직선 형태 데이터가 그려진다.

문항 11Pandas DataFrame과 연동

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt
import pandas as pd

data = {'월': [1, 2, 3, 4, 5, 6], '매출': [100, 120, 150, 130, 160, 180]}
df = pd.DataFrame(data)

df.plot(kind='line', x='월', y='매출', marker='o', title='월별 매출 추이')
plt.grid(True)
plt.show()
상세 풀이 보기
모범 답안
DataFrame의 월별 매출이 원형 마커가 있는 선 그래프로 나타나고, 제목은 '월별 매출 추이'이며 격자가 표시된다.
상세 풀이

df.plot은 DataFrame 열을 바로 그래프로 그린다. x는 월, y는 매출이고 grid(True)는 배경 격자를 켠다.

문항 12그래프에 텍스트와 화살표 추가하기

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 10, 100)
y = x**2

plt.plot(x, y)
plt.title("Annotation Example")
plt.text(2, 60, "y = x^2", fontsize=15)
plt.annotate('최저점', xy=(0, 0), xytext=(2, 20),
             arrowprops=dict(facecolor='black', shrink=0.05))
plt.show()
상세 풀이 보기
모범 답안
제목이 'Annotation Example'인 y=x² 곡선 그래프가 나타나고, 그래프 안에 'y = x^2' 텍스트와 원점 최저점을 가리키는 화살표 주석이 표시된다.
상세 풀이

linspace는 0부터 10까지의 x값을 만들고 y=x**2로 포물선 데이터를 만든다. text와 annotate는 그래프 위에 설명을 추가한다.

문항 13스타일 시트 적용하기

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt

plt.style.use('ggplot')

plt.plot([1, 2, 3, 4], [10, 20, 15, 25])

상세 풀이 보기
모범 답안
ggplot 스타일이 적용된 선 그래프가 나타나며 제목은 'ggplot 스타일 적용 결과'이다.
상세 풀이

style.use('ggplot')은 그래프의 배경, 격자, 색감 등 전체 시각 스타일을 ggplot 느낌으로 바꾼다.

문항 143D 산점도 그리기

다음 코드를 실행했을 때 화면에 나타나는 그래프를 그리시오.

import matplotlib.pyplot as plt
import numpy as np

np.random.seed(0)
fig = plt.figure()
ax = fig.add_subplot(111, projection='3d')

x = np.random.standard_normal(100)
y = np.random.standard_normal(100)
z = np.random.standard_normal(100)

ax.scatter(x, y, z, c='r', marker='o')
ax.set_title("3D 산점도 (구운몽의 연구 데이터)")
plt.show()
상세 풀이 보기
모범 답안
제목이 '3D 산점도 (구운몽의 연구 데이터)'인 3차원 좌표 공간에 빨간 원형 점 100개가 흩어져 나타난다.
상세 풀이

projection='3d'는 3차원 축을 만든다. x, y, z 세 배열이 각각 3D 좌표가 되며 scatter가 빨간 원형 점을 표시한다.
