문항 11. 숫자 맞추기 게임

평가 조건: secret_number가 50이고, 사용자가 50을 입력했다고 가정한다.

아래 코드를 실행했을 때 나타나는 출력 결과를 서술하시오.

import random

secret_number = random.randint(1, 100)
print("1부터 100 사이의 숫자를 맞춰보세요!")

while True:
    try:
        guess = int(input("추측한 숫자: "))
        if guess < secret_number:
            print("더 큰 숫자입니다!")
        elif guess > secret_number:
            print("더 작은 숫자입니다!")
        else:
            print(f"정답입니다! 숫자는 {secret_number}였습니다.")
            break
    except ValueError:
        print("숫자만 입력해주세요.")

random.randint로 만든 secret_number가 50이라고 고정하면, 사용자가 50을 입력했을 때 guess와 secret_number가 같다. 따라서 else 블록이 실행되어 정답 메시지를 출력하고 break로 반복문이 종료된다.

문항 22. 간단한 계산기

평가 조건: 첫 번째 숫자 10, 연산자 +, 두 번째 숫자 20을 입력했다고 가정한다.

아래 코드를 실행했을 때 나타나는 출력 결과를 서술하시오.

def calculate(x, operator, y):
    if operator == '+':
        return x + y
    elif operator == '-':
        return x - y
    elif operator == '*':
        return x * y
    elif operator == '/':
        if y == 0:
            return "0으로 나눌 수 없습니다."
        return x / y
    else:
        return "잘못된 연산자입니다."

num1 = float(input("첫 번째 숫자: "))
op = input("연산자 (+, -, *, /): ")
num2 = float(input("두 번째 숫자: "))

result = calculate(num1, op, num2)
print(f"결과: {result}")

문항 33. 랜덤 비밀번호 생성기

평가 조건: 사용자가 비밀번호 길이로 8을 입력했다고 가정한다. 비밀번호 문자는 랜덤이므로 정확한 문자 대신 출력 형식을 서술한다.

아래 코드를 실행했을 때 나타나는 출력 결과를 서술하시오.

import random
import string

def generate_password(length=12):
    # 대소문자, 숫자, 특수문자를 포함하는 문자셋 생성
    characters = string.ascii_letters + string.digits + string.punctuation
    # 무작위로 문자를 선택하여 합침
    password = "".join(random.choice(characters) for i in range(length))
    return password

pw_length = int(input("생성할 비밀번호의 길이를 입력하세요: "))
new_password = generate_password(pw_length)
print(f"생성된 비밀번호: {new_password}")

생성된 비밀번호: 길이가 8인 무작위 문자열
상세 풀이

generate_password(8)은 대문자, 소문자, 숫자, 특수문자 중에서 8개를 무작위로 골라 이어 붙인다. random.choice를 사용하므로 실행할 때마다 실제 비밀번호 문자는 달라질 수 있다.

def count_words_in_file(filename):
    try:
        with open(filename, 'r', encoding='utf-8') as f:
            content = f.read()
            words = content.split()
            return len(words)
    except FileNotFoundError:
        return f"'{filename}' 파일을 찾을 수 없습니다."

        add_contact()

        break

문항 61. 환율 정보 가져오기 (API 활용)

평가 조건: API 요청이 정상적으로 성공하고 KRW 환율 값을 받아왔다고 가정한다. 실제 환율 숫자는 실행 시점에 따라 달라진다.

아래 코드를 실행했을 때 나타나는 출력 결과를 서술하시오.

import requests

def get_exchange_rate(base_currency='USD'):
    try:
        url = f"https://open.er-api.com/v6/latest/{base_currency}"
        response = requests.get(url)
        data = response.json()
        
        if data['result'] == 'success':
            krw_rate = data['rates']['KRW']
            print(f"기준 통화: {base_currency}")
            print(f"현재 원/달러 환율: 1 {base_currency} = {krw_rate:.2f} KRW")
    except Exception as e:
        print(f"환율 정보를 가져오는 데 실패했습니다: {e}")

get_exchange_rate('USD')

requests.get으로 환율 API에 요청하고, JSON의 result가 success이면 rates에서 KRW 값을 꺼낸다. 환율은 실시간 데이터이므로 숫자는 실행 시점에 따라 달라질 수 있다.

문항 72. 웹사이트 제목 크롤링

평가 조건: https://www.google.com 에 정상 접속되어 title 태그가 Google이라고 가정한다.

아래 코드를 실행했을 때 나타나는 출력 결과를 서술하시오.

import requests
from bs4 import BeautifulSoup

def get_website_title(url):
    try:
        response = requests.get(url)
        soup = BeautifulSoup(response.content, 'html.parser')
        title = soup.title.string
        print(f"웹사이트 '{url}'의 제목: {title.strip()}")
    except Exception as e:
        print(f"제목을 가져오는 데 실패했습니다: {e}")

get_website_title("https://www.google.com")

문항 94. 파일 확장자별 정리 프로그램

평가 조건: organize_folder 함수는 정의만 되어 있고 실제 호출문은 없다고 가정한다.

아래 코드를 실행했을 때 나타나는 출력 결과를 서술하시오.

import os
import shutil

def organize_folder(target_dir):
    if not os.path.exists(target_dir):
        print("폴더가 존재하지 않습니다.")
        return

    for filename in os.listdir(target_dir):
        filepath = os.path.join(target_dir, filename)
        if os.path.isfile(filepath):
            ext = filename.split('.')[-1]
            ext_dir = os.path.join(target_dir, ext)
            
            if not os.path.exists(ext_dir):
                os.makedirs(ext_dir)
            
            shutil.move(filepath, os.path.join(ext_dir, filename))
    print("정리가 완료되었습니다.")

문항 105. 간단한 GUI 메모장 (Tkinter)

평가 조건: GUI 실행이 가능한 일반 PC 환경에서 실행한다고 가정한다.

아래 코드를 실행했을 때 나타나는 출력 결과를 서술하시오.

import tkinter as tk
from tkinter import filedialog

def save_file():
    content = text_area.get(1.0, tk.END)
    file_path = filedialog.asksaveasfilename(defaultextension=".txt")
    if file_path:
        with open(file_path, 'w', encoding='utf-8') as f:
            f.write(content)

root = tk.Tk()
root.title("인수샘의 초간단 메모장")
text_area = tk.Text(root)
text_area.pack(expand=True, fill='both')

menu = tk.Menu(root)
root.config(menu=menu)
file_menu = tk.Menu(menu)
menu.add_cascade(label="파일", menu=file_menu)
file_menu.add_command(label="저장", command=save_file)

root.mainloop()
